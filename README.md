#  Projet Blog - Site de Réservation d'Événements

Ce projet est un module **Blog** intégré dans un site web de réservation d'événements. Il permet d’ajouter, afficher et gérer des articles de blog.

##  Fonctionnalités:

- Ajouter un article de blog avec :
  - Titre
  - Auteur
  - Contenu
- Affichage des blogs dans une liste
- Interface utilisateur simple et intuitive

##  Technologies utilisées:

- HTML
- CSS
- PHP
- MySQL (base de données)
- XAMPP (ou tout autre serveur local)

##  Architecture MVC:

Le projet suit le modèle MVC :
- **Model** : gère la base de données et les requêtes SQL
- **View** : contient le HTML et CSS
- **Controller** : fait le lien entre les vues et les données
